EletroCharge

Aponte a câmera do celular para o QR Code

Como instalar:

  • Aponte a câmera do celular pro QR Code acima
  • Toque no link que aparecer (abre no navegador)
  • Toque em "Instalar EletroCharge no celular" na tela de login
  • Confirme — o ícone aparece na tela inicial

O celular precisa estar na mesma rede Wi-Fi deste computador para conseguir abrir o link.
